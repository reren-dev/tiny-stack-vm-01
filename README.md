A tiny stack VM for the [tiny-stack-vm-01-run-20261122](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty on [make.fun](https://make.fun): one `main.ts` runs all 40 bytecode programs of make.fun's tiny stack ISA and writes each program's output bytes and exit code. Full ISA: 32-bit wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their own exit codes.
